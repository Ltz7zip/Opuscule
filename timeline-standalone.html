操作指南

鼠标 · 触控板

  • 悬停轴线浮出圆形 +，点一下在该时刻新建时间点
  • 悬停轴线下方浮出虚线色带，点一下新建时间段（纪元）
  • 拖拽色带 / 两端整段平移 / 改这条纪元的起止
  • 拖拽空白处平移画布（按住轴线下方拖也可以）
  • 滚轮 / 触控板左右移动时间轴；⌘/Ctrl + 滚轮（或双指捏合）缩放
  • 右键框选拉出选框，松手选中相交的记录
  • 拖动选中项整组一起平移

键盘

  • ?打开 / 关闭这份指南
  • VH选择模式 / 只拖画面模式
  • +−F放大 / 缩小 / 适应内容
  • ← →左右平移（按住 Shift 走得更快）
  • ⌘Z撤销删除或复制
  • ⌘D复制当前选中的记录
  • Delete删除选中的记录（可以撤销）
  • Esc关掉浮层 / 取消框选 / 中断拖拽

编辑卡片

  • 标题 · 描述边打边存，停顿半秒或点到别处就落库
  • 封面方块纪元点它换配色；时间点暂无封面
  • 日期行点开年 / 月 / 日选择器，精确到天
