# P5.2：修改密码

- Date: 2026-10-20
- Status: P5.2 completed
- Predecessor: `docs/plans/20261020-p5.1-prod-settings.md`
- Design doc: §7

## 目标

补最小账号安全操作：

1. 登录用户可改密码（当前密码 + 新密码）。
2. 当前密码错误/新密码 <8/与旧相同 → 400。
3. 修改后当前 session 保持登录。
4. 不做忘记密码/邮件重置/2FA。
5. owner 在个人主页看到修改密码面板。

## 交付

- `POST /api/auth/password/`，SessionAuth + CSRF。
- `set_password` + `update_session_auth_hash`。
- ChangePasswordPanel（当前/新/确认），前端校验。
- 测试：成功改密并保持 session；错误当前密码/弱密码拒绝；总计 80 tests。

## 验收

- 改密后 `check_password` 新密码为真，session 仍 authenticated。
- 错误当前密码/弱密码 → 400，旧密码不变。
- 80 tests；budget PASS。

## 不在本切片

- 忘记密码/邮件重置/2FA。
- 其他设备 session 失效（Django session 不轮换）。
- 密码强度策略/泄露检测。
