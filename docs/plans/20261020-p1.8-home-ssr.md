# P1.8：Home SSR，公开内容路由收口

- Date: 2026-10-20
- Status: P1.8 completed
- Predecessor: `docs/plans/20261020-p1.7-profile-ssr.md`
- Design doc: §4.6 / §9

## 目标

把首页纳入同一 SSR 管线，完成“公开内容路由”这一层：

1. `/` 服务端输出公开世界首屏（标题/简介/集合/卡片），hydration 后可交互。
2. 复用 `initial.kind` 分支和单一 hydration entry。
3. 公开内容路由：Home + Wiki + Explore + Profile 全部 SSR。
4. Workspace/登录/注册/搜索/回收站/邀请仍 CSR；不冒充全站 SSR。

## 交付

- `PublicHome` 支持 `initialWorld`，SSR 跳过首屏 fetch。
- `entry-server` 增加 `renderHome`；`entry-client` 支持 `kind: home`。
- dev/prod server 增加 `/` SSR 分支。
- SSR bundle 52.94 kB / 10.53 kB gzip；client budget 不变。
- 浏览器验证首页 raw HTML/hydration/卡片/集合。

## 验收

```sh
cd frontend
npm run build:all && npm run preview:ssr
curl -s http://127.0.0.1:5175/   # HTML 含 雾海纪年/public-card
```

- 5175 Home 200；hydration 0 errors；6 张卡片/4 个 section。
- Wiki/Explore/Profile SSR 回归。
- Workspace 等受保护路由仍 CSR/需登录。
- 47 backend tests 保持；budget PASS。

## 不在本切片

- Workspace/登录态 SSR；受保护数据的服务端注入。
- 多进程部署/缓存/流式/监控；SSR E2E 自动化。
- 首页内容个性化（登录后不同首屏）。
