# P4.8：可信代理 IP 与限流键

- Date: 2026-10-20
- Status: P4.8 completed
- Predecessor: `docs/plans/20261020-p4.7-account-lockout.md`
- Design doc: §7 / §9

## 目标

让登录/注册限流在反向代理后按真实客户端 IP 生效，同时默认不信任可伪造头：

1. 默认只用 `REMOTE_ADDR`。
2. `TRUST_PROXY_HEADERS=1` 时才读 `X-Forwarded-For` 第一段。
3. 登录/注册共用该 throttle。
4. 不改账号锁定/认证语义。

## 交付

- `ClientIpScopedRateThrottle`（apps/common/throttle.py）。
- settings `env_bool` + `TRUST_PROXY_HEADERS`（默认 False）。
- 测试：默认忽略伪造 XFF；trusted 时不同 XFF 独立计数；总计 70 tests。
- deploy env 示例注释。

## 验收

- 默认 10 次不同 XFF 仍共用一个 127 桶，第 11 次 429。
- trusted 时 203.0.113.10 打满 429，203.0.113.11 仍 400。
- 70 tests；budget PASS。

## 不在本切片

- 多级代理/可信跳数校验；Cloudflare 等平台专用头。
- Redis 共享计数；账号锁定审计/解锁 UI。
- 邀请/搜索限流。
