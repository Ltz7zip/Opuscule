# P4.10：搜索标题优先排序

- Date: 2026-10-20
- Status: P4.10 completed
- Predecessor: `docs/plans/20261020-p4.9-search-users.md`
- Design doc: §4.7

## 目标

搜索结果原来只按更新时间；标题命中应与正文命中区分：

1. 卡片：标题精确 > 标题前缀 > 标题包含 > 仅正文。
2. 世界：名称精确 > 名称前缀 > 名称包含 > 仅简介。
3. 同级仍按更新时间倒序；可见性规则不变。
4. 不改 API 结构/前端。

## 交付

- Cards SearchView 用 `Case/When` 注解 `search_rank`。
- 世界结果同样按名称 rank。
- 测试：正文命中 vs 标题命中，标题排前；总计 73 tests。

## 验收

- `/api/search/?q=雾`：title-match 在 body-match 前。
- 浏览器 `/search?q=雾`：雾港 > 世界概览 > 船长·莉薇娅。
- 73 tests；budget PASS。

## 不在本切片

- 分页/has_more/相关度打分（TF-IDF/BM25）。
- 搜索 SSR。
