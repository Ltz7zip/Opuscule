# P1.4：公开 Wiki SSR/hydration 试点

- Date: 2026-10-20
- Status: P1.4 completed (dev pilot; production SSR not wired)
- Predecessor: `docs/plans/20261020-p1.3-share-ssr.md`
- Design doc: §4.6 / §9
- ADR: ADR-0019

## 目标

从“独立分享页”推进到**真正的应用路由 SSR**，但把范围限制在公开 Wiki：

1. `/w/<world>/wiki[/:card]` 由 Node/Vite SSR 返回带正文的 HTML。
2. 客户端对同一棵树 `hydrateRoot`，不重复拉取初始世界/卡片数据。
3. 其他路由仍由同一 server 的 SPA fallback 提供，不破坏现有应用。
4. 明确这是 dev pilot：不宣称生产 SSR 已部署。

## 交付

- `src/ssr/entry-server.tsx`：`renderToString(WikiPage)`，接受初始 world/card。
- `src/ssr/entry-client.tsx`：`hydrateRoot` 同一组件树；初始数据来自 `window.__INITIAL__`。
- `server.mjs`：Vite middleware + SSR 路由 + SPA fallback + API 预取；`npm run dev:ssr` 监听 5174。
- `WikiPage` 支持 `initialWorld`/`initialCard`，SSR 时不发初始 fetch。
- `ThemeToggle` 首次渲染固定 dark，mount 后读 localStorage，避免 hydration mismatch。
- 服务端 meta/canonical/OG/noindex 规则与 SPA 对齐。

## 验收

```sh
cd frontend
npm run dev:ssr
curl http://127.0.0.1:5174/w/wuhai/wiki/fog-harbor/   # HTML 含 h1/正文
```

- 浏览器 5174 Wiki 页无 hydration/控制台错误；初始 HTML 有正文。
- 点击 Wiki 链接由 SSR server 返回新页；`/explore` fallback 到 SPA 正常。
- 私有/不存在卡片 404。
- 390/1280 无溢出。

## 不在本切片

- **生产 SSR 构建/部署**：没有 `build:ssr`、生产静态资源、Nginx/Node 进程管理。
- 只有 Wiki SSR；Explore/Profile/Home 仍客户端渲染。
- SSR 匿名会话；不注入登录用户/角色。
- 没有流式 SSR、缓存、SSR 级测试/E2E、错误边界/超时策略。
- 分享页仍保留，作为无 JS 预览面。
