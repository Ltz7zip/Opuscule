# P4.1：世界时间线（MVP）

- Date: 2026-10-20
- Status: P4.1 completed
- Predecessor: `docs/plans/20261020-p3.9-health.md`
- Design doc: §4.6 / §6.1
- ADR: ADR-0023

## 目标

新增一个独立的世界观 feature，而不是塞进 Wiki/编辑器：

1. 独立 `apps.timelines` + `TimelineEntry`。
2. 公开世界时间线只读；owner/editor 可增删。
3. 按年份排序；可关联本世界卡片。
4. 独立 lazy 页面，不加载 Tiptap。
5. 非成员不可写；私有世界 404；跨世界卡片 400。

## 交付

- `TimelineEntry`：world/card/year/era/title/description/created_by。
- `GET /api/worlds/<slug>/timeline/` + entries CRUD（editor/owner）。
- `/w/<world>/timeline` lazy TimelinePage：垂直时间线、年份/纪年、添加/删除、卡片链接。
- Wiki/工作区入口；390/1280 响应式。
- 测试：公开只读、editor 增改删、私有 404、outsider 403、跨世界卡 400；总计 61 tests。

## 验收

- 浏览器创建 487/潮汐历/白塔沉没；列表/DB 正确；删除后 0。
- 公开只读；editor/owner 可写。
- 61 tests；budget PASS。

## 不在本切片

- 时间线编辑表单（当前只有创建/删除）、排序手动调整、分组/筛选。
- 多时间线/分支时间线/纪元区间/BCE 标签。
- 时间线分享/SSR/sitemap。
- 媒体/批量导入。
