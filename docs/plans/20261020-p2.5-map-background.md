# P2.5：地图背景图上传

- Date: 2026-10-20
- Status: P2.5 completed
- Predecessor: `docs/plans/20261020-p2.4-map-pan.md`
- Design doc: §4.6

## 目标

让抽象网格地图可以放一张世界底图：

1. owner 上传 PNG/JPEG/WebP，最大 4 MB。
2. 保存到 `media/world-map-backgrounds/`；公开地图显示。
3. owner 可移除；editor/非成员不能改。
4. 服务端校验大小、MIME、文件头。
5. 不做裁剪/缩放/媒体库。

## 交付

- `World.map_background` FileField + migration 0009。
- `POST/DELETE /api/worlds/<slug>/map/background/` owner-only。
- map API 返回绝对 `background_url`。
- MapPage 背景图层 + owner 上传/移除控件。
- tests：owner 上传/公开读取/删除；editor 403；非法内容 400；总计 75 tests。

## 验收

- 浏览器 owner 上传 PNG：背景 URL `/media/world-map-backgrounds/...`，图片显示。
- 移除后 URL 为空、文件删除。
- 75 tests；budget PASS。

- 媒体库/多图层/瓦片。
