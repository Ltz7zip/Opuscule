# P4.5：公开搜索加入世界结果

- Date: 2026-10-20
- Status: P4.5 completed
- Predecessor: `docs/plans/20261020-p4.4-rss-feed.md`
- Design doc: §4.7 / §6.1

## 目标

公开搜索原来只返回卡片；世界名/简介可搜但无入口。补：

1. `/api/search/?q=` 返回 `worlds`（最多 8）。
2. 只含公开、未软删世界；world 参数作用域内不返回世界结果。
3. SearchPage 增加“公开世界”区，再接卡片结果。
4. 空态条件改为世界+卡片都为空。

## 交付

- SearchView `world_results`；空查询返回 `worlds: []`。
- SearchWorldResult 类型/API/UI。
- 测试：公开世界出现、私有不出现、world 作用域无世界结果；总计 65 tests。

## 验收

- 浏览器 `/search?q=雾`：
  - 1 个公开世界“雾海纪年”
  - 3 条公开卡片（世界概览/雾港/船长·莉薇娅）
- 65 tests；budget PASS。

## 不在本切片

- 世界搜索分页/排序权重/高亮。
- 用户/成员搜索。
- 全站搜索 SSR。
- 私密世界索引。
