目标：在同一内容与登录态下，字体、颜色、间距、组件几何与版式与原站一致。
保留现有功能（编辑、改密码、主题、无障碍）；功能多出来的部分按原站组件语言落进区块。

## 2. 与原站的结构差异（保留功能后的取舍）

- 原站匿名个人页没有「编辑资料 / 修改密码 / 新建世界 / 回收站」；我们保留，并把它们收进
  「账户」区块，视觉沿用原站卡片规格，不改变主信息层级。
- 原站导航只有 公开世界 / 我的世界 / 登录 / 退出；我们额外保留 搜索、主题切换、进入工作区，
  以次级灰色文本/图标并入导航，不新增浮层。
- 原站以深色为唯一主题；我们保留浅色，但深色作为默认并作为像素基准。

## 4. 验收口径

- 同内容、同登录态下比较；数据不同（用户名、世界数）不作为差异。
- 关键几何误差 ≤1px，颜色为原站 token，字体为自托管 Geist/DM Serif。
- 额外功能只允许出现在原站没有的区块中，且不得改变共有元素的尺寸与位置。
