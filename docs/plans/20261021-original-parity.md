  「账户」区块，视觉沿用原站卡片规格，不改变主信息层级。

### 第 14 轮：点击白闪修复（2026-10-21）

现象：点击公共页 tile/导航进行整页跳转时，视频帧中能看到 1 帧纯白画布（YAVG 235），随后才进入新页深色背景；开发与生产 SSR 均复现，初始加载也会白闪。

根因：新文档在渲染阻塞 CSS 到达前先绘制浏览器默认白色画布，`html { background: var(--background) }` 来不及生效，属于 MPA 导航的首帧，不是 React 状态或动画。

修复：在 `index.html`、`server.mjs`、`server.prod.mjs` 的 `<head>` 首部加入内联 pre-paint 样式：暗色 `html/body` 画布 + `html[data-theme="light"]` 白色 + `color-scheme`，先于所有外部 CSS 生效。

验证：1280×800 录制点击 `探索 -> 雾海纪年 Wiki`，修复前出现 YAVG 235 白帧；修复后开发/生产视频均无 >150 亮度帧，也无接近空白的暗帧；页面内容正常切换。SSR 首页与 SPA `/login` 的 HTML 均包含该内联样式。
