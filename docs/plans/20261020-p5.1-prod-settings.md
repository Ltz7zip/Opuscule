# P5.1：生产安全 settings 环境化

- Date: 2026-10-20
- Status: P5.1 completed
- Predecessor: `docs/plans/20261020-p4.10-search-ranking.md`
- Design doc: §9 / deploy

## 目标

把生产配置从硬编码 dev 值改成环境变量，并让 Django deploy check 通过：

1. `DJANGO_SECRET_KEY` / `DJANGO_DEBUG` / `DJANGO_ALLOWED_HOSTS`。
2. CSRF trusted origins、SSL redirect、secure cookies、HSTS、proxy SSL。
3. SMTP mailer（默认仍 console，便于本地）。
4. 默认值保持本地开发不变；不引入新依赖。

## 交付

- settings `env_list`/`env_int`/`env_bool`；env 驱动安全项。
- MAILERS env 化（SMTP host/port/user/password/TLS）。
- `deploy/.env.example` 补生产变量。
- `manage.py check --deploy` 在完整生产 env 下 0 issues。

## 验收

- `DJANGO_DEBUG=0 ... manage.py check --deploy` → System check identified no issues。
- 默认 dev `make ci` 仍通过。
- 默认 DEBUG=True、console mailer 不变。

## 不在本切片

- gunicorn/systemd/Nginx 实际运行。
- Postgres 切换/迁移演练。
- 密钥管理服务/邮件实际投递。
- 多环境 settings 拆分。
