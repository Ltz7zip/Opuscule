# P3.3：世界 ZIP 导入（MVP）

- Date: 2026-10-20
- Status: P3.3 completed
- Predecessor: `docs/plans/20261020-p3.2-world-export.md`
- Design doc: §6.1

## 目标

让 P3.2 的导出可以往返：

1. owner 上传 Opuscule 导出的 ZIP，创建新世界。
2. 保留集合父子关系、卡片 body/Tiptap JSON、地图标记。
3. 新世界默认私有，不自动公开。
4. 限制 ZIP 大小/解压总量/路径，事务失败回滚。
5. 前端在 `/worlds/new` 提供“从 ZIP 导入”。

## 交付

- `POST /api/worlds/import/`（multipart，owner 配额 7）。
- `apps/worlds/importing.py`：stdlib zip/json 校验与导入，无新依赖。
- 新世界默认 `is_public_read=False`，owner membership。
- 前端 `importWorld` + 新建世界页导入入口；成功后跳工作区。
- 测试：导出→导入 roundtrip、非法 ZIP、未登录；总计 53 tests。

## 验收

- 后端 roundtrip 测试：集合/卡片/地图标记数量与 body 文本保留。
- 浏览器文件选择器可打开；非法 ZIP 返回“不是有效的 ZIP 文件”，无 CSRF 错误。
- ZIP >5MB、路径穿越、解压 >20MB、非 v1 格式拒绝。
- 53 backend tests；budget PASS。

## 不在本切片

- 导入到已有世界/合并策略；覆盖确认。
- 媒体/附件导入；只有 JSON/纯文本。
- 大世界异步导入/进度/取消/限流。
- 导入审计事件/导入历史/回滚。
- 浏览器端 valid ZIP 上传未自动化（后端 roundtrip 已覆盖）。
