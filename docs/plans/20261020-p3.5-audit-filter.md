# P3.5：审计筛选与导入文件展示

- Date: 2026-10-20
- Status: P3.5 completed
- Predecessor: `docs/plans/20261020-p3.4-import-e2e-audit.md`
- Design doc: §6.1

## 目标

让 P3.4 的导入审计真正可发现：

1. 审计 API 支持按 action 过滤 + limit。
2. 活动记录 dialog 增加“全部/导入/成员邀请/设置公开”筛选。
3. 导入事件显示源文件名。
4. 未知 action 返回 400；limit 有上限。

## 交付

- `GET /api/worlds/<slug>/audit/?action=...&limit=...`
- `WorldAuditView` 过滤/限制；未知 action 400。
- `WorldAuditDialog` 本地分组筛选；`metadata.filename` 展示。
- 测试：audit filter 返回仅目标 action；未知 action 400。

## 验收

- 用真实 `world.imported` 事件（filename mini-import.zip）打开活动记录：
  - 全部显示 1 条；
  - 导入筛选仍 1 条；
  - 成员筛选 0 条并显示空态。
- 53 backend tests；budget PASS。
