# P0.6：世界设置、世界切换与配额

- Date: 2026-10-20
- Status: P0.6 completed
- Predecessor: `docs/plans/20261020-p0.5-world-onboarding.md`
- Design doc: §4.6 / §6.1

## 目标

补上 P0.5 的“创建后只能公开、不能改名、不能切换”的断点：

1. owner 在工作区打开「世界设置」，改名称/简介/公开状态。
2. 有多个世界时，工作区顶栏可切换世界。
3. 每个账号最多拥有 7 个世界（设计稿 §6.1 的上限）。
4. editor 不能改世界设置；只有 owner 可以。

## 交付

- `WorldSettingsDialog`：name/description/is_public_read，保存后更新工作区标题、侧栏和公开按钮。
- Sidebar 设置按钮从占位变为可用；非 owner 禁用。
- Topbar workspace 世界切换 `<select>`：只在 `session.worlds.length > 1` 时出现。
- 后端创建配额：owner membership >=7 时返回 400。
- 测试：配额、owner settings、editor 403 继续覆盖。

## 不在本切片

- 世界删除、封面、成员/邀请、角色管理。
- 自定义 slug；名称/简介以外的高级设置。
- 世界配额按公开/私有分类计数（当前按 owner membership 总数）。
- 前端 E2E 自动化。
