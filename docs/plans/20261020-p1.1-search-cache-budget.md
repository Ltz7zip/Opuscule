# P1.1：公开搜索、缓存头与 JS 预算门禁

- Date: 2026-10-20
- Status: P1.1 completed (SSR deferred)
- Predecessor: `docs/plans/20261020-p0.10-audit.md`
- Design doc: §4.6 / §9

## 目标

1. 公开站可以搜索公开 Wiki 卡片，私有世界/卡片/软删世界不出现。
2. 搜索结果带世界、卡片链接与正文片段；搜索页 lazy，不加载编辑器。
3. 公开目录/个人主页返回可共享缓存头；搜索也有短缓存。
4. 把公开站 JS/CSS 预算变成可执行门禁，避免 fan 问题回归。

## 交付

- `GET /api/search/?q=&world=`：标题/正文 `icontains`，最多 30 条；只查 `is_public_read`、`is_public`、非辅助、未软删。
- `/search` lazy 页面 + Topbar 搜索入口；空查询/无结果/错误态。
- `Cache-Control: public`：Explore 60s + SWR；公开个人主页 60s；搜索 30s。
- `check:budget` Node 脚本与 `make budget`：entry ≤120 kB、Workspace ≤160 kB、CSS ≤40 kB gzip。
- 测试：搜索命中/私有/软删/空查询/world filter、Explore 缓存头。

## 验收

```sh
cd backend
.venv/bin/python manage.py test          # 37 tests
cd ../frontend
npm run build && npm run check:budget
```

- 浏览器 `/search?q=灯塔` 命中公开卡片“雾港”，链接到 Wiki。
- 私有世界内容不出现。
- 预算门禁 entry/Workspace/CSS 全部 PASS。
- 390/1280 搜索页无横向溢出。

## 不在本切片

- **SSR/SSG、HTML 首屏、SEO meta** 未做；当前仍是 SPA + API。
- 中文分词/相关性排序/拼写纠错/FTS 索引；当前是 SQLite `icontains` 上限 30。
- 服务端共享缓存（CDN/Redis）；只设置浏览器/代理可用的 `Cache-Control`。
- 登录用户/私有 Wiki 搜索、搜索历史、搜索分析。
