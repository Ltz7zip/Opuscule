# P2.1：世界地图模块（MVP）

- Date: 2026-10-20
- Status: P2.1 completed (MVP)
- Predecessor: `docs/plans/20261020-p1.5-ssr-production.md`
- Design doc: §4.6 / §6.1
- ADR: ADR-0021

## 目标

把“地图”做成独立 feature/app，而不是塞进工作区：

1. 新 `apps.maps` app + `MapMarker`；地图数据不混入 Card body。
2. 公开世界地图只读；editor/owner 可以放标记、拖动、删除。
3. 标记可关联本世界卡片，可标注地点/事件/人物/笔记。
4. 地图页 lazy，不加载 Tiptap；不影响公开站预算。
5. 私有/软删世界不可读；非成员不可写。

## 交付

- `MapMarker`：world、card(null)、label、kind、x/y(0..1)、created_by。
- `GET /api/worlds/<slug>/map/`：公开只读 + can_edit + markers。
- `POST /api/worlds/<slug>/map/markers/`；`PATCH/DELETE .../<id>/`（editor/owner）。
- 跨世界 card / 越界坐标 400。
- 前端 `/w/<world>/map` lazy MapPage：网格画布、标记、点击放置、拖动更新、删除、卡片关联。
- Wiki/工作区入口；390/1280 响应式。

## 验收

```sh
cd backend
.venv/bin/python manage.py test          # 47 tests
cd ../frontend
npm run build && npm run check:budget
```

- owner 点击地图 → 填名称 → 放置；刷新后仍在。
- 拖动标记保存位置；删除确认生效。
- 公开地图只读；私有世界 404；viewer/outsider 写入 403。
- MapPage 是独立 lazy chunk，不加载 Tiptap。

## 不在本切片

- 地图背景图/瓦片/缩放/平移/多图层；只有抽象网格画布。
- 标记编辑名称/类型/关联卡片的 UI（当前只支持创建与拖动/删除）。
- 地图 SSR/分享页/嵌入；地图不进 sitemap。
- 批量导入、坐标拾取、碰撞/边界约束、历史版本。
- 地图权限细分（viewer 可见，editor 可写；当前沿用世界角色）。
