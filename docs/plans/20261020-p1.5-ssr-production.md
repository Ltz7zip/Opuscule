# P1.5：SSR 生产构建与独立 server

- Date: 2026-10-20
- Status: P1.5 completed (single-process preview; deployment topology still manual)
- Predecessor: `docs/plans/20261020-p1.4-ssr-pilot.md`
- Design doc: §4.6 / §9
- ADR: ADR-0020

## 目标

把 P1.4 的 Vite dev SSR 试点推进到“可构建、可独立启动”的生产形态：

1. client build 生成 manifest + SSR hydration entry。
2. SSR server bundle 独立构建到 `dist-ssr/`。
3. 生产 server 不依赖 Vite middleware，静态服务 `dist/`，SSR Wiki，SPA fallback。
4. API/robots/sitemap/share/admin 反代到 Django。
5. 仍只做 Wiki SSR；明确部署拓扑/多实例未接。

## 交付

- `vite.config.ts`：`manifest: true`，多入口 main + `ssr-client`。
- `npm run build` 生成 client manifest；`npm run build:ssr` 生成 `dist-ssr/entry-server.js`。
- `npm run build:all`；`npm run preview:ssr` 启动 5175。
- `server.prod.mjs`：静态资产、SSR 路由、SPA fallback、Django API/robots/sitemap/share/admin 反代。
- `check-budget.mjs` 改为读 manifest，按 entry 的 transitive imports 计算预算。
- 404/私有世界、hydration、SPA `/explore` 均验证。

## 验收

```sh
cd frontend
npm run build:all
npm run check:budget
npm run preview:ssr      # :5175
```

- 5175 Wiki raw HTML 含 h1/正文/initial；hydration 0 errors。
- 5175 `/explore` 走 SPA + `/api` 反代正常。
- 5175 私有/不存在卡片 404。
- budget entry/Workspace/CSS PASS。

## 不在本切片

- Nginx/Node 进程管理、容器/部署、TLS、CDN/SSR 缓存、流式 SSR。
- 多页 SSR（Explore/Profile/Home）与登录态 SSR。
- SSR 自动化测试/E2E；生产域名/健康检查。
- SSR server 仍是单进程本机预览，不是生产高可用架构。
