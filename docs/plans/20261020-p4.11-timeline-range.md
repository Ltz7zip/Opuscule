# P4.11：时间线年份区间

- Date: 2026-10-20
- Status: P4.11 completed
- Predecessor: `docs/plans/20261020-p4.10-search-ranking.md`
- Design doc: §4.6

## 目标

事件不总是单年发生：

1. `TimelineEntry.end_year` 可选，表示持续区间。
2. 服务端校验 end_year >= year。
3. 时间线显示 `487–490`。
4. 创建/编辑表单支持结束年份。
5. 不拆成新的 Era/区间模型。

## 交付

- model 字段 + migration 0002。
- serializer `end_year` + 跨字段校验。
- TimelinePage 结束年份输入/编辑回填/范围显示/前端禁用非法区间。
- 测试：创建 487–490、更新为 488、end_year<year → 400；总计 76 tests。

## 验收

- 浏览器创建 487–490，列表显示 `487–490`，DB end_year=490。
- 76 tests；budget PASS。
