# P3.2：世界数据导出（ZIP）

- Date: 2026-10-20
- Status: P3.2 completed
- Predecessor: `docs/plans/20261020-p3.1-ci-deploy.md`
- Design doc: §6.1

## 目标

给 owner 一个真正的数据带走能力，不依赖外部服务：

1. `GET /api/worlds/<slug>/export/` 下载 ZIP。
2. ZIP 内含 `world.json`、`README.md`、`wiki/<slug>.md`。
3. 包含世界元信息、集合、卡片、地图标记；不含邀请/会话/其他用户隐私。
4. 只有 owner 可导出；editor/viewer/匿名拒绝；软删世界 404。
5. 世界设置 dialog 提供“导出 ZIP”按钮。

## 交付

- `apps/worlds/export.py`：stdlib `zipfile`/`json`，无新依赖。
- `WorldExportView`：owner-only，`application/zip`，`no-store`。
- 前端 `exportWorld` + 设置 dialog 下载按钮（blob/object URL）。
- 后端测试 3 个：ZIP 内容、权限、软删；总计 50 tests。

## 验收

- owner 点击“导出 ZIP”得到 `wuhai-export.zip`；ZIP 有预期文件。
- editor 403；匿名拒绝；软删 404。
- ZIP 不含 invites/session。
- 50 backend tests；budget PASS。

## 不在本切片

- ZIP 导入/恢复（只导出）。
- 媒体/附件打包；当前卡片是 Tiptap JSON/纯文本。
- 大世界异步导出/进度/限流；当前同步内存 ZIP。
- 导出审计事件；没有 export audit action。
- 地图背景/瓦片打包。
