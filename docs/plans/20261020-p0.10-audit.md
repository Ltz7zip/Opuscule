# P0.10：治理审计 + 所有权转移端到端

- Date: 2026-10-20
- Status: P0.10 completed (audit retention/export deferred)
- Predecessor: `docs/plans/20261020-p0.9-ownership-trash.md`
- Design doc: §4.6 / §6.1
- ADR: ADR-0017

## 目标

1. 记录世界治理动作：创建/设置/公开/删除/恢复、成员增删改、邀请创建/撤销/接受、所有权转移。
2. owner 可在工作区查看活动记录。
3. 关闭 P0.9 的缺口：实际点击一次所有权转移，确认原 owner 降 editor、目标变 owner。
4. 审计事件只读；不提供前端删除/修改。

## 交付

- `WorldAuditEvent`：world/actor/target_user/action/metadata/created_at。
- 服务端 `log_world_event()`，在 create/update/publish/delete/restore、member、invite、transfer 路径写事件。
- `GET /api/worlds/<slug>/audit/`：owner-only，最近 100 条。
- 前端 `WorldAuditDialog`：owner Sidebar History 入口；中文 action_label、actor/target/time、空态/错误态。
- 测试：owner 可读、editor 403、事件顺序/动作覆盖。
- 浏览器：审计可见；真实所有权转移完成并验证角色。

## 验收

```sh
cd backend
.venv/bin/python manage.py test          # 33 tests
cd ../frontend
npm run build
```

- 创建/成员/邀请/删除/恢复/转移均产生对应事件。
- owner 可在 dialog 中看到事件；editor 看不到入口/接口 403。
- 转移后 traveler 变 editor，transfer_member 变 owner；测试后清理。
- 390/1280 no overflow。
