# P4.4：公开 RSS feed

- Date: 2026-10-20
- Status: P4.4 completed
- Predecessor: `docs/plans/20261020-p4.3-timeline-filter.md`
- Design doc: §4.7 / §8

## 目标

给公开 Wiki 一个可订阅出口，不依赖前端/登录：

1. `/feed.xml`：全站公开卡片的 RSS 2.0。
2. `/w/<world>/feed.xml`：单个公开世界的 RSS。
3. 只含 `is_public=True`、非辅助、世界公开且未软删的卡片；最多 50 条。
4. XML 转义；`Cache-Control: public, max-age=60`。
5. 站点与 world share 页自动发现 feed。

## 交付

- `apps/common/feeds.py`：stdlib XML 拼装 + `xml.sax.saxutils.escape`。
- 路由 + `<link rel="alternate">`（index 与 share base/world）。
- 测试：公开/私有/软删过滤、转义、私有 world 404；总计 63 tests。

## 验收

- `/feed.xml` 200 RSS，6 个公开 item。
- `/w/wuhai/feed.xml` 200，同样 item。
- `/w/nope/feed.xml` 404。
- index HTML 有 feed autodiscovery。
- 63 tests；budget PASS。

## 不在本切片

- Atom/JSON Feed、分页/ETag/Last-Modified、更新推送。
- 时间线/地图的 feed。
- feed 阅读器 UI/统计。
