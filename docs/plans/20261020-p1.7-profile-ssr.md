# P1.7：Profile SSR

- Date: 2026-10-20
- Status: P1.7 completed
- Predecessor: `docs/plans/20261020-p1.6-explore-ssr.md`
- Design doc: §4.6 / §9

## 目标

把公开个人主页也纳入同一 SSR 管线：

1. `/u/<username>` 服务端输出 profile 首屏（名字/简介/精选世界/卡片），hydration 后可交互。
2. 复用同一个 `initial.kind` 分支和 hydration entry，不新建构建管线。
3. 私有/不存在 profile 仍 404；匿名 SSR。
4. Profile 编辑仍只在 SPA 登录后可用；SSR 不注入用户态。

## 交付

- `ProfilePage` 支持 `initialProfile`；SSR 跳过首屏 fetch。
- `entry-server` 增加 `renderProfile`；`entry-client` 支持 `kind: profile`。
- dev/prod server 增加 `/u/<username>` SSR 分支。
- SSR bundle 46.97 kB / 9.73 kB gzip；client budget 不变。
- 浏览器验证 `/u/traveler` raw HTML/hydration/精选世界/卡片。

## 验收

```sh
cd frontend
npm run build:all && npm run preview:ssr
curl -s http://127.0.0.1:5175/u/traveler   # HTML 含 旅人/profile-shell
```

- 5175 Profile 200；hydration 0 errors；精选世界/最近卡片可见。
- Wiki/Explore SSR 回归；其他路由 SPA fallback。
- 私有/不存在 profile 404。
- 47 backend tests 保持；budget PASS。

## 不在本切片

- Home/Workspace SSR；登录态 SSR；Profile 编辑 SSR。
- 多进程部署/缓存/流式/监控；SSR E2E 自动化。
