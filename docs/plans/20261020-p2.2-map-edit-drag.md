- Status: P2.2 completed

## 目标

关闭 P2.1 的两个缺口：

1. 选中 marker 后可编辑名称/类型/关联卡片。
2. 真实 pointer 拖动 marker，位置通过 PATCH 持久化，并做浏览器端到端验证。

## 交付

- `MapPage` 选中面板：查看 →「编辑」表单（名称/类型/卡片）→ 保存；取消/切换选择重置编辑态。
- 拖动逻辑验证：pointerdown/move/up；拖动后 PATCH；刷新后坐标保持。
- 更新 P2.1 的缺口说明；不新增 API/schema。

## 验收

- 浏览器选中 marker → 编辑名称/类型 → 保存；地图/DB 更新。
- pointer 拖动 marker → PATCH 200；DB x/y 变化。
- 390/1280 无溢出；控制台 0 错误。
- 47 tests 保持；budget PASS。
