# P1.2：SEO 元信息、sitemap 与 CI

- Date: 2026-10-20
- Status: P1.2 completed (SSR still deferred)
- Predecessor: `docs/plans/20261020-p1.1-search-cache-budget.md`
- Design doc: §4.6 / §9

## 目标

1. 公开页面有可抓取的 title/description/canonical/Open Graph/Twitter 元信息。
2. 私有路由（工作区/回收站/邀请/登录/注册/新建）noindex。
3. 提供 `/robots.txt` 与 `/sitemap.xml`，只列公开世界、公开卡片、公开个人主页。
4. 增加 CI workflow，跑后端 check/migrations/tests + 前端 build/budget。
5. 明确 SSR 未做：这些是元信息/索引改进，不是 HTML 首屏服务端渲染。

## 交付

- `useDocumentMeta` hook：title/description/robots/canonical/og/twitter；公共页 index，私有页 noindex。
- `robots.txt`：允许公开，禁止 trash/login/register/worlds-new/invite/search；指向 sitemap。
- `sitemap.xml`：首页/探索/公开世界 Wiki/公开卡片/公开 profile；排除私有、软删、私有卡片、私有 profile。
- GitHub Actions `.github/workflows/ci.yml`：Python 3.13 + Node 24；后端 tests；前端 build + `check:budget`。
- 测试：robots 内容/缓存、sitemap 包含/排除。

## 验收

```sh
cd backend
.venv/bin/python manage.py test          # 40 tests
cd ../frontend
npm run build && npm run check:budget
```

- `/robots.txt` 指向 `/sitemap.xml`。
- `sitemap.xml` 含 `/w/wuhai/wiki/fog-harbor`、`/u/traveler`，排除私有/软删。
- 浏览器 Wiki meta `index,follow` + canonical；搜索/工作区 `noindex,nofollow`。
- CI 文件存在；本轮未在 GitHub runner 实跑。

## 不在本切片

- **React SSR/SSG、服务端 HTML 首屏、动态 OG 图、JSON-LD** 未做。
- 社交爬虫若不执行 JS，仍只能看到 `index.html` 的静态 meta；本切片主要服务执行 JS 的搜索引擎。
- sitemap 分页/索引文件/图片 sitemap、lastmod 精度、canonical host 配置。
- CI 未实际 push/运行；没有部署流程。
