# P1.6：Explore SSR 扩容

- Date: 2026-10-20
- Status: P1.6 completed
- Predecessor: `docs/plans/20261020-p1.5-ssr-production.md`
- Design doc: §4.6 / §9
- ADR: ADR-0022

## 目标

在 Wiki SSR 之外，增加公开 Explore 的服务端 HTML，继续验证公共壳的可扩展性：

1. `/explore` SSR 输出世界列表（真实 HTML），hydration 后保留搜索输入。
2. 同一条 SSR server/client 管线，不新增第二套依赖。
3. 生产 preview 5175 直接可用；其他路由仍 SPA fallback。
4. 不把 Explore SSR 冒充全站 SSR（Profile/Home 仍 CSR）。

## 交付

- `ExplorePage` 支持 `initialWorlds`，SSR 跳过初始 fetch。
- `entry-server` 增加 `renderExplore`；`entry-client` 按 `initial.kind` hydrate Wiki 或 Explore。
- dev/prod server 增加 `/explore` SSR 分支。
- SSR bundle 31.06 kB / 7.36 kB gzip；单 client hydration entry 复用。
- 浏览器验证 real HTML/hydration/搜索输入。

## 验收

```sh
cd frontend
npm run build:all && npm run preview:ssr
curl -s http://127.0.0.1:5175/explore   # HTML 含 雾海纪年/explore-card
```

- 5175 Explore 200，HTML 含世界卡；hydration 0 errors；搜索输入可交互。
- Wiki SSR 仍正常；SPA fallback 其他路由。
- budget 不变；47 tests 保持。

## 不在本切片

- Profile/Home/Workspace SSR；登录态 SSR。
- 多进程/部署/缓存/流式；生产高可用。
- SSR 自动化测试/E2E；SSR cache headers。
