# P4.7：账号级登录锁定

- Date: 2026-10-20
- Status: P4.7 completed
- Predecessor: `docs/plans/20261020-p4.6-auth-throttle.md`
- Design doc: §7 / §9

## 目标

在 IP 限流之外补账号级防暴力破解：

1. 已存在账号连续 5 次密码错误 → 锁定 15 分钟。
2. 锁定期内即使密码正确也 429。
3. 成功登录重置失败计数/锁定。
4. 未知用户名不暴露锁定状态。
5. 不改用户名/密码/CSRF 语义。

## 交付

- `UserProfile.failed_login_count` / `locked_until` + migration 0003。
- LoginView 检查/计数/锁定/成功重置；找不到 profile 时创建。
- 测试：5 次失败锁定→正确密码 429；3 次失败后成功归零；总计 68 tests。

## 验收

- 错误密码 5 次后 profile.locked_until 非空。
- 第 6 次正确密码返回 429 且提示“尝试次数过多”。
- 成功登录重置 count/locked_until。
- 68 tests；budget PASS。

## 不在本切片

- 验证码/2FA/邮件通知。
- 解锁 UI/管理员解锁/审计锁定事件。
- 分布式共享锁定（数据库字段本身共享，但无并发锁）。
- 未知用户名的常量时间响应。
