## 目标

给部署拓扑补最小可观测入口：

1. `/api/health/` 检查数据库连接，失败 503。
2. SSR `/healthz` / `/readyz` 返回 web 进程状态。
3. Nginx 示例显式路由 `/healthz`。
4. 不引入监控依赖；不做深度依赖检查。

## 交付

- Health API 返回 `{status,service,database}`；DB 异常 503 `{status:degraded}`。
- SSR dev/prod server 返回 JSON liveness。
- 测试 DB 故障 mock，503。
- Nginx `/healthz`。

- 58 backend tests；budget PASS。
