# P4.12：搜索关键词高亮

- Date: 2026-10-20
- Status: P4.12 completed
- Predecessor: `docs/plans/20261020-p4.11-timeline-range.md`
- Design doc: §4.7

## 目标

搜索结果里直接标出命中词，不引入 HTML 注入：

1. 世界名/简介、创作者名/简介、卡片标题/snippet 高亮。
2. 用 React 文本分段 + `<mark>`，不用 dangerouslySetInnerHTML。
3. 大小写不敏感；特殊字符按字面匹配。
4. 不改变搜索 API/排序。

## 交付

- SearchPage `Highlight` 组件 + `activeQuery`。
- CSS `mark` 轻量背景，不抢标题层级。
- 浏览器 `/search?q=雾` 12 个 mark。

## 验收

- 卡片标题“雾港”渲染为 `<mark>雾</mark>港`。
- 世界/创作者/正文中的“雾”高亮。
- 76 tests；budget PASS。

## 不在本切片

- 服务端 snippet 的高亮范围/多关键词/词干。
- 分页/has_more。
- 搜索结果 SSR。
