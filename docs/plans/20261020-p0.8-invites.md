# P0.8：一次性邀请链接

- Date: 2026-10-20
- Status: P0.8 completed (email invite/ownership transfer deferred)
- Predecessor: `docs/plans/20261020-p0.7-members.md`
- Design doc: §4.6 / §6.1

## 目标

成员管理不能只支持“已经注册且知道用户名”的人。owner 需要生成可分享的邀请链接：

1. 生成一次性 editor/viewer 邀请，7 天有效。
2. 公开 `/invite/<token>` 页面显示世界、角色；未登录可先去登录/注册。
3. 登录/注册后回到邀请页接受，加入世界并跳工作区。
4. 已使用/过期/撤销的邀请不可接受。
5. owner 可列出、复制、撤销邀请；token 不能暴露给非 owner 的列表接口。

## 交付

- `WorldInvite`：world/token/role/created_by/expires_at/max_uses/used_count/revoked_at。
- `GET/POST /api/worlds/<slug>/invites/`（owner）；`DELETE .../invites/<id>/` 撤销。
- `GET /api/invites/<token>/` 公开信息；`POST /api/invites/<token>/accept/` 登录接受。
- 一次性语义：used_count < max_uses；默认 max_uses=1，expires 7 天。
- 前端 MembersDialog 邀请区：角色选择、生成、复制、撤销、状态。
- 新增 `/invite/:token` lazy 页面；登录/注册支持安全 `next` 回跳。
- 测试：创建/撤销、接受、复用 410、过期 410、未登录 401/403、editor 不能建邀请。

## 验收

- 生成邀请 → 匿名打开 → 登录 → 回邀请页 → 接受 → 工作区。
- 邀请 used_count=1；再次接受 410。
- owner 撤销后 valid=false。
- 390/1280 邀请页和成员 dialog 无横向溢出。
