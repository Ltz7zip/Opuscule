# P4.9：公开搜索加入创作者

- Date: 2026-10-20
- Status: P4.9 completed
- Predecessor: `docs/plans/20261020-p4.8-proxy-throttle.md`
- Design doc: §4.7 / §6.1

## 目标

公开搜索补创作者结果，但只暴露已经公开的身份：

1. `/api/search/?q=` 返回 `users`（最多 8）。
2. 条件：profile `is_public=True`，且至少有一个公开、未软删世界。
3. 匹配 display_name/headline/username。
4. `world=` 作用域内不返回创作者。
5. 不返回 email/私有信息。

## 交付

- SearchView `user_results`；空查询 `users: []`。
- SearchUserResult 类型/API/UI；SearchPage “公开创作者”区。
- 测试：公开创作者出现、私有 profile/仅私有世界不出现、world 作用域为空；总计 72 tests。

## 验收

- 浏览器 `/search?q=旅`：1 位公开创作者 @traveler 旅人。
- 世界/卡片区为空时不显示空态。
- 72 tests；budget PASS。

## 不在本切片

- 创作者分页/排序权重/高亮。
- 私密 profile 或仅私有世界用户索引。
- 用户搜索 SSR。
