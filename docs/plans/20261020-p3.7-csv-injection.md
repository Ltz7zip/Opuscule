# P3.7：审计 CSV 公式注入防护

- Date: 2026-10-20
- Status: P3.7 completed
- Predecessor: `docs/plans/20261020-p3.6-audit-csv.md`
- Design doc: §6.1

## 目标

审计 CSV 可能包含用户可控的 username/metadata；Excel/LibreOffice 会把以
`= + - @` 或 tab/CR 开头的单元格当公式。需要在服务端统一转义。

## 交付

- `_csv_safe()`：所有文本单元格；危险前缀加单引号 `'`。
- 覆盖时间/动作/操作者/对象/元数据；csv writer 继续处理逗号/换行。
- 测试：target username `+formula` 在 CSV 中写成 `'+formula`。

## 验收

- 55 backend tests；CSV 测试通过。
- 合法数字时间不被误改；普通文本保持不变。
- 不做前端 CSV 拼接。

## 不在本切片

- 审计保留/不可篡改/签名。
- 导入历史/撤销。
