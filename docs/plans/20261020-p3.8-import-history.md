# P3.8：导入历史与撤销

- Date: 2026-10-20
- Status: P3.8 completed
- Predecessor: `docs/plans/20261020-p3.7-csv-injection.md`
- Design doc: §6.1

## 目标

让导入可被发现、可撤销：

1. `GET /api/worlds/imports/`：owner 最近 100 个导入世界（含已撤销）。
2. `POST /api/worlds/<slug>/undo-import/`：只允许撤销导入世界；软删到回收站。
3. `/worlds/new` 显示最近导入，支持“撤销导入”。
4. 撤销写入 DELETED 审计，metadata `reason=import_undo`。

## 交付

- `WorldImportHistoryView`：基于 `world.imported` 审计，去重、owner-only。
- `WorldImportUndoView`：校验来源/DELETED 审计/撤销邀请/软删。
- 前端历史列表 + confirm + 撤销后移除；已撤销不显示按钮。
- 测试：import→history→undo→can_undo false/Second 404；非导入世界 400；总计 57 tests。

## 验收

- 浏览器导入有效 ZIP → `/worlds/new` 显示“最近导入” → 撤销确认 → 行消失。
- DB：世界 `deleted_at` 非空；DELETED 审计 `reason=import_undo`。
- 57 backend tests；budget PASS。

## 不在本切片

- 物理清除/保留期限/从回收站恢复的 UI（已有 `/trash` 通用恢复）。
- 导入历史分页/搜索/批量撤销。
- 媒体/异步导入。
