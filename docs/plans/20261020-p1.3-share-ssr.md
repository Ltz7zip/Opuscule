# P1.3：服务端分享页（SSR 预览面）

- Date: 2026-10-20
- Status: P1.3 completed (不是应用 SSR/hydration)
- Predecessor: `docs/plans/20261020-p1.2-seo-ci.md`
- Design doc: §4.6 / §9
- ADR: ADR-0018

## 目标

补上“社交/爬虫不执行 JS 时看不到内容”的缺口，但**不假装完成 React SSR**：

1. Django 直接渲染公开世界/卡片/个人主页的分享页，HTML 首屏有标题、正文摘要、OG 元信息。
2. 分享页不加载 React/Tiptap，不承担编辑/交互；只作为社交预览与无 JS 可读面。
3. 分享页 noindex，canonical 指回 SPA 的公开 URL，避免 SEO 重复内容。
4. Wiki 卡片提供“分享”按钮，复制 `/share/w/<world>/<card>/`。
5. 私有/软删内容仍 404。

## 交付

- `share/w/<slug>/`、`share/w/<slug>/<card>/`、`share/u/<username>/` Django 模板。
- 服务端 meta：title/description/og:title/og:description/og:type/og:url/twitter/canonical/noindex。
- 分享页内联 CSS，无 JS、无外部资源；390/1280 响应式。
- `WikiPage` 分享按钮（clipboard + prompt fallback）。
- 测试：公开卡片/世界/profile 200 + meta；私有/软删/私有卡片 404；缓存头。

## 验收

```sh
cd backend
.venv/bin/python manage.py test          # 43 tests
cd ../frontend
npm run build && npm run check:budget
```

- 直连 Django `/share/w/wuhai/fog-harbor/` 返回 HTML 正文与 OG；无 favicon 404。
- 私有世界分享页 404；私有 profile 404。
- Wiki 分享按钮变成“已复制分享链接”。

## 不在本切片

- **React SSR/SSG、hydration、服务端路由整站** 未做；分享页是独立只读 HTML，不是 SPA 的服务端渲染。
- 分享页不渲染完整 RichText 结构/图片，只输出纯文本；没有 OG 图。
- 分享页 noindex；SEO 主 URL 仍是 SPA（依赖执行 JS 的搜索引擎）。
- 没有短链/点击统计/社交平台 API。
