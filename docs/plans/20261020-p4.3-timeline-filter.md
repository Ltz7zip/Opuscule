# P4.3：时间线纪元筛选

- Date: 2026-10-20
- Status: P4.3 completed
- Predecessor: `docs/plans/20261020-p4.2-timeline-edit.md`
- Design doc: §4.6

## 目标

时间线开始积累后，需要按纪元快速筛选：

1. 从当前条目自动生成“全部纪元 + 各 era”筛选。
2. 筛选只影响显示，不改变排序/数据。
3. 无条目时显示“这个纪元还没有事件”。
4. 不新增 API/schema。

## 交付

- TimelinePage `eraFilter` 状态 + `eras`/`visibleEntries`。
- 纪元筛选按钮组；空态文案。
- 浏览器：旧历/潮汐历两条 → 潮汐历筛选只剩 1 条。

## 验收

- 筛选按钮显示“全部纪元/旧历/潮汐历”。
- 选择潮汐历只显示 487 条目。
- 61 tests；budget PASS。
