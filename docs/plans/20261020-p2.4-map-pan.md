# P2.4：地图平移与边界夹取

- Date: 2026-10-20
- Status: P2.4 completed
- Predecessor: `docs/plans/20261020-p2.3-map-zoom.md`
- Design doc: §4.6

## 目标

补齐缩放后的可用性：

1. 1–3× 缩放下支持平移。
2. 平移边界夹取，避免画布露出空白。
3. 编辑者可在“放置/移动”模式切换；公开地图默认拖动平移。
4. 平移后点击/拖动坐标仍正确。

## 交付

- MapPage `pan` + `mode` + panRef。
- `clampPan` 依据画布尺寸/zoom 限制。
- 控件：重置同时归零平移；移动/放置模式。
- `mapPoint()` 扣除 pan 后再逆变换。
- 浏览器 2× + 平移 120/60px 后放点；DB x≈0.428/y≈0.442。

## 验收

- 2.0× 平移后 transform `translate(120px,60px) scale(2)`。
- 平移后中心点击落点约 42.8%/44.2%。
- 公开地图可拖动平移；编辑模式切换正常。
- 61 tests；budget PASS。

## 不在本切片

- 瓦片/背景图/多图层。
- 滚轮缩放/触摸双指/惯性。
- 地图 SSR/分享。
