# P2.3：地图缩放

- Date: 2026-10-20
- Status: P2.3 completed
- Predecessor: `docs/plans/20261020-p2.2-map-edit-drag.md`
- Design doc: §4.6

## 目标

让抽象网格地图可以放大细看，且不破坏点击放置/拖动：

1. 1.0×–3.0× 缩放，按钮 +/-/重置。
2. 缩放以画布中心为原点。
3. 点击/拖动坐标做逆变换，放大后仍落点准确。
4. 公开地图也可缩放；编辑权限不变。

## 交付

- MapPage `zoom` 状态 + `.map-world` transform。
- `mapPoint()` 反算归一化坐标。
- 缩放控件；阻止控件点击冒泡到画布。
- 浏览器在 2.0× 放置 marker（x≈0.5）并拖动（x≈0.56）。

## 验收

- 放大 2.0× 后中心点击落在 0.5/0.5。
- 拖动 marker 后 DB 坐标更新。
- 61 tests 保持；budget PASS。

## 不在本切片

- 平移/边界夹取/缩放中心跟随鼠标。
- 瓦片/背景图/多图层。
- 地图 SSR/分享。
