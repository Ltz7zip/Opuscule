- Date: 2026-10-20
- Status: P2.6 completed
- Predecessor: `docs/plans/20261020-p2.5-map-background.md`
- Design doc: §4.6 / §6.1

## 目标

让 P2.5 的背景图随世界导出/导入：

1. 导出 ZIP 增加 `map/background.<ext>`，`world.json` 记录 path/filename。
2. 导入校验安全路径、扩展名、文件头、≤4 MB。
3. 旧 ZIP（无 map_background）继续可导入。
4. ZIP 上限从 5 MB 提到 10 MB，容纳 4 MB 背景 + 数据。

## 交付

- export：map/background 文件 + `world.json.world.map_background`。
- import：`_payload` 返回 archive；恢复背景文件；错误路径/格式拒绝。
- 测试：背景上传→导出→导入字节一致；总计 76 tests。
- UI 导入提示改为 10 MB。

## 验收

- 带背景的 ZIP 导入后 `world.map_background` 有文件且字节一致。
- 无背景旧 ZIP 仍可往返。
- 76 tests；budget PASS。
