# P3.6：审计活动 CSV 导出

- Date: 2026-10-20
- Status: P3.6 completed
- Predecessor: `docs/plans/20261020-p3.5-audit-filter.md`
- Design doc: §6.1

## 目标

给 owner 一条可离线审计/备份的活动记录出口：

1. `GET /api/worlds/<slug>/audit/export/` 输出 CSV。
2. 支持按 action 过滤；最多 5000 条。
3. UTF-8 BOM + CRLF，兼容 Excel；列：时间/动作/操作者/对象/元数据。
4. owner-only；unknown action 400；`no-store`。
5. 活动记录 dialog 增加“导出 CSV”。

## 交付

- `WorldAuditExportView`：stdlib `csv`/`io`/`json`。
- `exportWorldAudit` + dialog 按钮（当前“导入”筛选会带 action）。
- 测试：owner CSV/BOM/filter、editor/anon 403；总计 55 tests。

## 验收

- 浏览器活动记录点击“导出 CSV”下载 `wuhai-audit.csv`。
- CSV 含表头、世界导入、操作者、`mini-import.zip` 元数据。
- 53→55 tests；budget PASS。

## 不在本切片

- 审计分页/游标/时间范围/actor 过滤。
- 审计保留策略/不可篡改/签名。
- CSV 公式注入转义/超大导出流式输出（metadata 可含用户输入）。
- 导入历史/撤销。
