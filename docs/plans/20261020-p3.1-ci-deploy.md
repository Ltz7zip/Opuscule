# P3.1：本地 CI 门禁与部署拓扑草图

- Date: 2026-10-20
- Status: P3.1 completed (local CI); deployment config is a sketch
- Predecessor: `docs/plans/20261020-p1.8-home-ssr.md`
- Design doc: §9 / §10

## 目标

在继续加功能前，把“怎么证明没坏、怎么部署”补上：

1. 提供一条本地可执行的 CI 门禁：backend check/migration/tests + design HTML + client/SSR build + budget。
2. GitHub Actions 增加 design 校验，并构建 client + SSR。
3. 给出 Nginx/systemd/env 拓扑草图，明确未执行、未生产化。
4. 不引入 Docker 依赖，不 falsely claim 生产部署完成。

## 交付

- `scripts/ci.sh` + `make ci`：一条命令跑完整本地门禁。
- `scripts/check_design.py`：设计稿 HTML 结构校验。
- CI workflow：backend、design、frontend（`build:all`）。
- `deploy/nginx.conf.example`、systemd 示例、`.env.example`、README。

## 验收

```sh
make ci
# backend 47 tests; design PASS; client/SSR build; budget PASS
```

- `bash -n scripts/ci.sh` 通过。
- YAML 可解析（Ruby YAML）。
- 部署文件标记为 sketch，未执行 Nginx/systemd。
- 不提交 secrets。
