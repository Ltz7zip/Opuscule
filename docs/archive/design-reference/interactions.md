# 交互行为清单

> 来源：实际在 `app.notion.com` 上操作，逐条记录；每条尽量附 DOM 钩子作为证据。
> 标注 **【实测】** = 我亲手触发过；**【文案】** = 从页面文案/结构与推断得出，未亲手验证手感。

| # | 交互 | 触发方式 | 证据 |

| 1.1 | **斜杠命令菜单** | 空块输入 `/` | **【实测】** 菜单分四组：`建议`（AI 速记、HTML·嵌入）/ `基本区块` / `媒体` / `数据库`；每项右侧带快捷键别名；底部有 `关闭菜单 esc`；未滚到的分组显示"正在加载…"（虚拟滚动） |

## 5. 搜索 / 提问面板

**【实测】** 触发：侧边栏「搜索」按钮或 `⌘K`（面板底部提示 `→ 在新选项卡中打开` / `创建`）。

| 元素 | 内容 |
| --- | --- |
| 输入框占位 | `在 La vi.的工作空间 中搜索或提问...` |
| 右侧 | AI 提问按钮 |
| 过滤器行 | `Aa 仅搜索标题` / `创建者` / `在页面中` / `+ 筛选` |
| 结果分组 | 按时间分组，实测看到分组「今天」 |
| 底部操作 | `→ 在新选项卡中打开`、`创建` |

> 要点：**搜索框同时是 AI 提问入口**，这是 Notion 的一个关键设计——"找东西"和"问问题"共用一个入口。
