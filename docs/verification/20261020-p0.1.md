## 覆盖与缺口

- World / Collection / Card 的读、建、改；跨世界 collection 校验；slug 生成；revision 递增。
- 工作区侧栏、Tiptap 编辑、自动保存、手动保存、保存状态、加载/空/错误状态。
- 公开页只读分组；深/浅主题；390/1280 响应式。

未覆盖 / 明确缺口：

- **认证与权限**：写接口当前 `AllowAny`，仅限 localhost demo；P0.2 必须加 session/token、CSRF、世界权限。

- **SSR**：公开页仍是 Vite SPA；P0.2 拆 SSR 模板。
- **CollectionPage / CollectionView**：模型与 API 尚未实现。
- **Timeline / Hist / Map / Graph / 11 工具宿主**：未开始。
- **BlockNote → Tiptap 迁移器**：未实现；当前只存 Tiptap JSON。
- **无障碍审计**：有语义控件、aria-label、键盘 ⌘S，但未跑 axe/读屏；移动侧栏没有焦点陷阱。
- **长内容/极端数据**：未做 10k 表格、2k canvas 基准；未测超长标题与多语言混排。
- **生产构建**：`npm run build` 通过，但未用生产静态服务器端到端验证；bundle 645 kB 未拆包。
