## 已验证

- `GET /worlds/new` 登录后显示创建表单；未登录显示登录/注册 gate。
- 创建 `验收世界` 成功：201；自动生成 slug `world`；创建 owner membership、3 个空 Collection（人物/地点/事件）和 1 张根级“世界概览”卡。
- 创建后直达 `/w/world?card=7`；工作区可编辑，owner 显示“公开 Wiki”按钮。
- 点击“公开 Wiki”后 PATCH 成功，`/api/explore/` 出现该世界，`/w/world/wiki` 可匿名读取；无 `.tiptap` DOM。
- 创建页 390/1280 无横向溢出。
- 注册 `tester_p05` 后跳 `/worlds/new`，创建表单可用；测试用户和测试世界已清理，数据库当前只保留 `wuhai` / `traveler`。
- 后端 23 tests：create 匿名拒绝、bootstrap、owner PATCH、editor 403、public explore；原有 auth/card/wiki 测试继续通过。

## 明确缺口

- 世界名称/简介的工作区设置 UI 在 P0.5 时未做；P0.6 已补 WorldSettingsDialog。
- 没有世界删除、世界切换器、7 个私人世界上限、收藏/封面。
- 中文世界名的 slug 目前回退为 `world` / `world-2`，不是拼音；后续可让用户自定义 slug。
- 注册后没有邮箱验证/邀请/限流；世界创建没有配额检查。
- Wiki 的嵌套 Collection 投影仍未递归；空 Collection 只显示“空集合”。
- 创建世界没有 Tiptap，但工作区仍会加载 editor chunk（134.52 kB gzip）。
