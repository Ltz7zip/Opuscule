## 已验证

- `/`：公开页资源不含 `Workspace`/Tiptap；dev 网络请求 `hasTiptap=false`。
- `/explore`：只列 public-read 世界；`description/card_count/collection_count` 有值；匿名和登录都只出公开世界。
- `/w/wuhai/wiki`：公开 Wiki 索引 6 篇、左侧导航 6 条；无 `.tiptap` DOM。
- `/w/wuhai/wiki/livia`：公开卡片正文用轻量 `RichText` 渲染，3 个段落；无 `.tiptap` DOM。
- `/register`：注册页可打开；成功创建 `tester_p04`，自动登录并跳 `/u/tester_p04`；测试后已删除测试用户。
- `POST /api/auth/register/`：弱用户名/重名/弱密码有后端测试；CSRF 保护。
- 390/1280：explore、register、wiki、wiki card、profile 均无横向溢出。
- Production preview 首屏传输 JS 约 77.6 kB，资源列表不含 `Workspace`/Tiptap；Tiptap 只在 `/w/...` lazy chunk。
- 控制台 0 错误（公开页/Wiki/注册成功路径）。

## 性能结论

- 旧实现：所有页面静态 import 编辑器，production bundle 约 660 kB（gzip 208 kB），公开页也下载/初始化 Tiptap。
- 新实现：入口 73.37 kB gzip；公开页约 73–78 kB gzip；工作区 editor chunk 134.52 kB gzip，只在工作区加载。
- 顶栏移除 `backdrop-filter`；公开页没有常驻动画。
- 风扇问题的**高置信原因**是公开页加载 ProseMirror/Tiptap 与 dev 双执行；已消除公开页路径。若只在工作区仍出现，需要再用真实设备 profile，不能凭此记录宣称所有设备已解决。

## 明确缺口

- 仍是 SPA；公开页 SSR、边缘缓存、SEO/RSS 是 P1。
- Wiki 搜索仅前端过滤当前世界；无全文搜索、分页。
- Collection 嵌套投影未递归（当前 seed 是顶层）；P1 补。
- 注册是开放注册最小版：无邮箱验证、邀请、限流、密码重置；注册后没有世界创建向导。
- 探索无服务端筛选/分页/排序；只有公开世界。
- 新增页面没有自动化前端测试；只有 `tsc + build + Playwright` 手工路径。
- `Workspace` chunk 仍大（412 kB raw / 134.52 kB gzip）；后续可把 Tiptap 扩展再按需拆。
- 无 SSR/真实设备 Lighthouse budget；CI 预算未加。

## 结论

- 置信度：**B**。路由拆分、公开 Wiki/探索/注册主路径有后端测试 + 浏览器证据 + production chunk 数据；SSR、搜索、注册完整生命周期和真实设备性能仍未验收。
- 这是 P0.4 页面骨架与性能切片，不是完整公开站。
