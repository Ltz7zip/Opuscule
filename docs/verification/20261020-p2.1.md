## 已验证

- 浏览器 `/w/wuhai/map`：owner 点击画布 → 填“七钟楼” → 放置成功；API/DB 有 marker。
- 刷新/重新进入有 marker；选择 marker 后侧栏显示删除。
- 删除确认后 marker 从地图/DB 消失；测试后 markers=0。
- MapPage 是独立 lazy chunk（约 7 kB raw），不加载 Workspace/Tiptap。
- 公开地图只读；私有世界 404；outsider 写 403；越界坐标/跨世界 card 400（后端 test）。
- 390/1280 无横向溢出；控制台 0 错误。
- 当前库仍只有 `wuhai` / `traveler`。

## 明确缺口

- 拖动位置代码在 P2.1 时未端到端验证；P2.2 已补真实 pointer 拖动 + 编辑表单。
- 没有地图背景图/瓦片/缩放/平移；画布是抽象网格。
- 标记创建后不能改名称/类型/关联卡片；只能拖动/删除。
- 地图不 SSR/不分享/不进 sitemap；公开地图对爬虫只有 SPA meta。
- 没有地图 E2E/单元前端测试；无 git commit。

## 结论

- 置信度：**B**。独立 app/API/懒加载页面/创建删除/权限有 tests + 浏览器证据；拖动未端到端实测，地图能力仍是 MVP。
