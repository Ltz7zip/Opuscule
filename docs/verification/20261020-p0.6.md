## 明确缺口

- 世界删除/封面/成员邀请/角色管理未做。
- 没有 world settings 的独立页面；dialog 内只有名称/简介/公开。
- 配额按 owner membership 总数计数，不区分公开/私有；7 个上限是硬编码常量。
- 世界切换器只显示 session.worlds；没有搜索/分组；超过 7 个不会出现。
- 没有前端 E2E；设置/切换仍是 Playwright 手工路径。
- 无 git commit。

- 置信度：**B**。设置、切换、配额三条路径有后端测试 + 浏览器证据；删除/成员/封面仍是缺口。
