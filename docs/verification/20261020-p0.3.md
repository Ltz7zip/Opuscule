## 已验证

- 匿名 `GET /api/u/traveler/` 200；`is_owner=false`；只返回公开 world/card。
- 私有世界、私密卡片不出现在匿名 profile；置顶的私有 world ID 不出现在响应。
- `GET /api/profile/` 匿名 403；本人 200；`PATCH /api/profile/` 200。
- `is_public=false` 的 profile 匿名 404；本人 200。
- `javascript:` link 被清空；裸域名补 `https://`。
- 浏览器 1280：个人主页显示头像、简介、所在地、网站、链接、统计、精选世界、最近公开卡片、全部世界。
- 浏览器 390：头像 64px，`documentElement.scrollWidth=390`，无横向溢出。
- 本人编辑：打开面板 → 改一句话简介 → 保存 → PATCH 200 → 页面更新；已恢复原值。
- 登录后 Topbar 用户名是 `/u/traveler` 链接；移动端用户名隐藏时头像仍是个人主页链接。
- 控制台 0 错误。

## 明确缺口（P0.4 parity）

- 旧 `UserProfile.blocks` 拖拽排版、`layout` 单/双栏、`accent` 主题色编辑器未重建；`blocks/layout` 字段已在 P0.3 保留，P0.4 再决定编辑器。
- 链接只展示 seed 值；PATCH 支持 `links`，但 UI 暂无链接编辑器。
- 头像上传、自定义 note 区块、题材标签、最近动态（当前用最近公开卡片替代）未做。
- 关注/粉丝、个人主页评论未做。
- `seed_demo` 的 profile 是本地 demo；生产资料由用户填写。
- 公开主页目前是 SPA；公开站 SSR 仍未做。
- 没有前端自动化测试；仅有 TypeScript build + Playwright 手工验证。
- Bundle 660.45 kB（gzip 207.58 kB），未拆包。
