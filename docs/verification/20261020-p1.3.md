## 已验证

- 直连 Django `/share/w/wuhai/fog-harbor/`：
  - 200，HTML 含“雾港”、正文、canonical、`og:type=article`、`noindex,follow`
  - 无 favicon 404，控制台 0 错误
- `/share/w/wuhai/` 世界分享页列出公开卡片；`/share/u/traveler/` profile 分享页。
- 私有世界/私有卡片/私有 profile 404（后端 test）。
- 分享页 `Cache-Control: public, max-age=60`。
- 前端 Wiki 卡片“分享”按钮复制 `/share/w/wuhai/fog-harbor/`，状态变为“已复制分享链接”。
- 390/1280 分享页响应式；无编辑器 JS。
- 测试后数据库仍只有 `wuhai` / `traveler`。

## 明确缺口

- **没有 React SSR/SSG/hydration**；分享页不可交互，SPA 首屏仍是客户端渲染。
- 分享页正文是 `body_text` 纯文本，不保留 Tiptap 图片/列表层级；没有 OG 图片。
- 分享页 noindex；SEO 主 URL 仍依赖 SPA meta。
- 分享页使用 Django 8000 origin；生产需要反代/域名配置。
- 分享按钮只支持 clipboard/prompt，没有原生 share API 回退。
- 无前端 E2E；无 git commit。

## 结论

- 置信度：**B**。服务端 HTML/OG/分享按钮均有 tests + 浏览器证据；完整 SSR 明确未做。
