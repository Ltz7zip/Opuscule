## 已验证

- 匿名 `GET /api/worlds/wuhai/` 可读；`can_edit=false`、`role=null`；私有 card/collection 不出现在匿名世界详情中。
- 匿名写卡片 403；非成员写 403；owner 写 201/200。
- 私有世界 `is_public_read=false` 匿名详情 404；viewer 成员可读但 `can_edit=false`。
- `GET /api/auth/csrf/` 设置 CSRF cookie；`POST /api/auth/login/` 带 `X-CSRFToken` 成功。
- 登录后不带 CSRF 的 PATCH 403；带新 CSRF token 的 PATCH 200；`logout` 204，session 变匿名。
- 登录页错误密码：400 + 页面“用户名或密码错误”，不跳转。
- 登录页成功后跳转 `/w/wuhai`；owner 工作区可编辑，匿名工作区只读。
- 390 宽度：登录表单卡片 358px、高约 415px，`documentElement.scrollWidth=390`；工作区无横向溢出。
- 工作区保存：标题修改后 PATCH 成功，revision 递增；标题已恢复为“世界概览”。

## 明确缺口

- **注册/邀请**：未实现；登录页“注册”禁用。
- **成员管理 UI**：`WorldMembership` 只有 model/admin/seed；没有邀请、移除、角色切换界面。
- **限流/锁定**：登录没有失败次数限制；本地 demo 可接受，生产前必须加。
- **Cookie 安全**：本地 `CSRF_COOKIE_SECURE` / `SESSION_COOKIE_SECURE` 未开；生产必须 HTTPS + secure cookies。
- **私有世界列表**：匿名只看到公开世界；成员私有世界列表已按 membership 过滤，但没有专门 UI。
- **CSRF trusted origins**：只配置 127.0.0.1:5173 / localhost:5173；部署域名要替换。
- **默认 demo 密码**：`opuscule-demo` 只用于本机；生产必须用 `--password`/环境变量并删除 demo 用户。
- **Postgres / SSR / CollectionPage / Timeline / Hist / 11 工具宿主**：仍未开始。
- **前端测试**：只有 TypeScript build + 手工 Playwright；没有组件/E2E 自动化。
- **Bundle**：651.60 kB（gzip 205.88 kB），未拆包。
