- `/search?q=灯塔` 命中公开卡片“雾港”，显示世界名、正文片段与 Wiki 路径；链接 `/w/wuhai/wiki/fog-harbor`。

- Explore 响应 `Cache-Control: public, max-age=60, stale-while-revalidate=300`。
- `check:budget` 三项 PASS；`make budget` 可复跑。
- 390/1280 搜索页无横向溢出；控制台 0 错误。
- Topbar 重建后公共页搜索/探索/主题/工作区/登录链接正常。

## 明确缺口

- **SSR/SSG/SEO 未做**；首屏仍是 SPA + API 请求，爬虫/首屏 HTML 未优化。
- 搜索是 `icontains`，无分词/相关性/FTS；中文单字可搜，长尾性能未压测。
- 缓存只是响应头，没有 CDN/服务端共享缓存；搜索结果 30 条上限。
- 没有搜索历史/热词/分析；没有登录用户私有搜索。
- `check:budget` 是本地门禁，不是已运行的 CI（仓库还没有 CI workflow）。
- 无前端 E2E；无 git commit。

## 结论

- 置信度：**B**。搜索/缓存/预算主路径有 tests + 浏览器证据；SSR 明确未做。
