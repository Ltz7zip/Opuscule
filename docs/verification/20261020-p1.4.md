- 浏览器 5174 Wiki：hydration 成功，控制台 0 errors/warnings。
- 点击 `/w/wuhai/wiki/korr`：SSR server 返回新页，标题/正文正确。
- `/explore` 在同 server 走 SPA fallback，仍能加载公开世界。

- 390/1280 无横向溢出。

## 明确缺口

- **没有生产 SSR 构建/部署**：server.mjs 依赖 Vite dev middleware；没有 `build:ssr`、静态资源、Node 进程管理。
- 只有 Wiki 路由 SSR；Explore/Profile/Home 不是 SSR。
- SSR 只有匿名状态；不注入登录用户，工作区入口仍是指向 SPA 的链接。
- 没有 SSR 数据缓存/流式输出/错误边界/超时；每次请求直连 Django API。
- 没有 SSR 自动化测试/E2E；手工 Playwright 验证。
- 分享页（P1.3）仍保留，不等于完整 SSR。
- 无 git commit。

## 结论

- 置信度：**B**。Wiki SSR + hydration + SPA fallback 有实际 server/浏览器证据；生产化与多页 SSR 未做。
