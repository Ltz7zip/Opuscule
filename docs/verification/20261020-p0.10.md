## 明确缺口

- 只记录治理动作；卡片正文编辑仍有 CardRevision，不重复进 audit。
- 没有分页/筛选/导出/保留期限；只显示最近 100 条。
- 没有 IP/UA、不可篡改/外部审计；数据库层可改。
- 软删世界的事件随世界恢复保留，但 hard delete 会级联删除。
- 前端无 E2E；审计事件在测试后清理，无长期样本。

## 结论

- 置信度：**B**。审计主路径 + 转移 UI 真实点击均有证据；保留/不可篡改/导出未做。
- P0.9 的“转移 UI 未实测”缺口已关闭。
