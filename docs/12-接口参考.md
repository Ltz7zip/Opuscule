# 接口参考

> **文档版本：0.4.0-dev**
>
> 这是一份**接口字典**：把工作区（`/api/world/*`）与经典时间轴（`/api/*`）的
> 全部端点按功能分组列出来。它对应 [world/urls.py](../world/urls.py)、
> [timeline/urls.py](../timeline/urls.py) 两张路由表，**逐条抄录**，可以当作查手册用。
>
> 面向**刚学会 Python、还没写过 Web 应用**的读者：每张表附一句说明，
> 开头有一段「怎么读」。

---

## 1. 怎么读这张表

- **方法**列：`GET`（取数据）、`POST`（新建/动作）、`PUT`（整体更新）、
  `DELETE`（删除）。一个端点支持多种方法时用 `GET / PUT` 这样并列，
  具体行为见「作用」列。标 `—` 表示该方法不定（兜底接口）。
- **路径**列：都以 `/api/world/` 开头（时间轴那组以 `/api/` 开头）。
  **路径结尾不带斜杠**——这是刻意的约定，别加 `/`，否则可能触发重定向。
- `<doc_id>` / `<id>` 这类尖括号是**占位符**，实际请求里换成数字（如 `/api/world/documents/12`）。

**三个通用约定：**

1. **数据格式**：请求体和响应体基本都是 **JSON**。少数接口是例外：
   导出返回文件流（zip / markdown / csv）、媒体上传收 `multipart/form-data`、
   `maps/<doc_id>/background` 也收文件。
2. **CSRF**：浏览器里的写请求（POST/PUT/DELETE）由 Django 内置机制校验 **CSRF token**。
   接口函数大多标了 `@csrf_exempt`（因为前端是脚本轮询 + 自带 token 的约定），
   但**认证仍靠 session cookie**。
3. **错误对象**：失败时统一回 JSON，常见形态：

   ```json
   { "error": "接口不存在" }
   ```

   ```json
   { "need_login": true }
   ```

   `need_login` 出现时，前端据此弹出登录框。状态码一般是 400（参数问题）、
   401（未登录）、403（没权限）、404（找不到）。

**认证方式**：**session cookie**。你登录后浏览器带着 cookie，
后端通过 Django 的会话认出「你是谁、你在哪个世界、能不能编辑」。
没有额外的 token 头或 API Key。

## 2. 状态与世界

| 方法 | 路径 | 作用 |
| --- | --- | --- |
| GET | `/api/world/state` | 工作区启动快照：当前世界、我的权限、类型、文档树等一次给全 |
| GET / PUT | `/api/world/world` | 读 / 更新当前世界的属性（名称、描述、主题、体裁等） |
| GET / POST | `/api/world/worlds` | 列出我的世界 / 新建一个世界 |
| POST | `/api/world/worlds/<world_id>/switch` | 切换当前世界 |
| GET | `/api/world/activity` | 最近发生的事（通知中心的数据源） |

> `state` 是**页面首屏最关键的一次请求**——前端拿到它就能立刻把界面画出来。

## 3. 文档与回收站

| 方法 | 路径 | 作用 |
| --- | --- | --- |
| GET / POST | `/api/world/documents` | 列文档（可按 `type` / `parent` / `q` 过滤）/ 新建文档 |
| GET / PUT / DELETE | `/api/world/documents/<doc_id>` | 读 / 更新 / 删除（软删进回收站）一份文档 |
| POST | `/api/world/documents/<doc_id>/duplicate` | 复制一份文档（含卡片内容） |
| POST | `/api/world/documents/<doc_id>/restore` | 从回收站还原 |
| GET | `/api/world/trash` | 回收站列表 |
| POST | `/api/world/documents/<doc_id>/distribute` | 按某种规则给该文档自动铺开下一级（拆分/分发） |

> **一切内容都是文档**：文件夹、卡片、时间线、地图、看板……都是 `Document`，
> 靠 `document_type` 区分。所以「新建」这一个接口能建出所有类型。

## 4. 卡片 / 类型 / 属性

| 方法 | 路径 | 作用 |
| --- | --- | --- |
| GET / PUT | `/api/world/cards/<doc_id>` | 读 / 写一张卡片（属性值 + 区块正文） |
| GET / POST | `/api/world/types` | 列出实体类型 / 新建类型 |
| GET / PUT / DELETE | `/api/world/types/<type_id>` | 读 / 更新 / 删除一个类型 |
| GET / POST | `/api/world/types/<type_id>/properties` | 列出该类型的属性定义 / 新增属性 |
| GET / PUT / DELETE | `/api/world/properties/<property_id>` | 读 / 更新 / 删除一个属性定义 |

> 类型可以**继承**：子类型自动拥有父类型的全部属性定义，
> 所以读属性时是「往上把祖先的属性也收集齐」再返回。

## 5. 时间线与事件

| 方法 | 路径 | 作用 |
| --- | --- | --- |
| GET | `/api/world/timelines/<doc_id>` | 读某条时间线的整体状态（视图范围、分组等） |
| GET / POST | `/api/world/timelines/<doc_id>/events` | 列出事件 / 新建事件 |
| POST | `/api/world/timelines/<doc_id>/apply-preset` | 给这条时间线套用一套日历预设 |
| GET / PUT / DELETE | `/api/world/events/<event_id>` | 读 / 更新 / 删除一个事件 |
| POST / DELETE | `/api/world/events/<event_id>/cards` | 给事件关联 / 解除关联一张卡片 |
| POST / DELETE | `/api/world/events/<event_id>/cards/<card_id>` | 同上，针对指定卡片 |

> 事件有「年/月/日/时」四级精度；`cards` 那两条是事件与卡片的**多对多**连接。

## 12. 发布

| 方法 | 路径 | 作用 |
| --- | --- | --- |
| GET / POST | `/api/world/publish` | GET 看站点状态；POST 发布 / 重新发布 |
| GET | `/api/world/publish/preview` | 发布差异预览（这次会新增/更新/下架哪些文档） |

## 13. 账号与协作

| 方法 | 路径 | 作用 |
| --- | --- | --- |
| GET / POST | `/api/world/auth/me` | 读当前登录者与权限；POST 用于刷新会话信息 |
| POST | `/api/world/auth/renew` | 会话续期（快到期时前端调用） |
| GET | `/api/world/auth/invite` | 校验邀请码是否有效（`?code=…`） |
| POST | `/api/world/auth/register` | 注册（可能需要邀请码） |
| POST | `/api/world/auth/login` | 登录 |
| POST | `/api/world/auth/logout` | 登出 |

## 14. 版本

| 方法 | 路径 | 作用 |
| --- | --- | --- |
| GET | `/api/world/documents/<doc_id>/versions` | 列出某文档的历史快照 |
| GET / POST | `/api/world/documents/<doc_id>/versions/<index>` | 读某个快照 / 按它回滚 |

> 每次保存文档会留一个快照，注意两点：**90 秒内同一作者的连续保存会合并**，

## 16. 请求处理与权限把关

**兜底接口**：

| 方法 | 路径 | 作用 |
| --- | --- | --- |
| — | `/api/world/<任意未匹配路径>` | 未知的 `/api/world/*` 一律回 JSON 404 `{"error":"接口不存在"}` |

这个兜底（`views.api_fallback`）的作用是：**别把一张 HTML 错误页丢给前端**。
前端永远期待 JSON，拿到 HTML 会解析失败。有了它，任何拼错的接口都回一份
规规矩矩的 JSON 错误。

**一次写请求在服务端会经过三道关**：

```
① ActiveWorldMiddleware     解析"当前世界"写进请求上下文
        （会话选定 → 自己的第一个世界 → 兜底）
② EditPermissionMiddleware  只对写方法（POST/PUT/PATCH/DELETE）生效：
        数据库一个用户都没有？ → 放行（首次安装例外）
        没登录？              → 401 {"need_login": true}
        登录了但没编辑权限？   → 403
③ CSRF 校验（Django 内置）
```

**读永远公开**（游客也能浏览工作区），**写需要登录 + 在世界里有权限**。
少数路径在写守门人的白名单里（登录/注册、在线心跳、新建/切换世界），
因为它们发生在「还没有身份 / 还没有自己的世界」的时刻。

## 17. 经典时间轴应用（`/api/*` 与页面）

这一组由 `timeline` 应用提供，和上面那套世界接口**互相独立**。

### 17.1 页面路由

| 方法 | 路径 | 作用 |
| --- | --- | --- |
| GET | `/legacy` | 经典时间轴独立页 |
| GET | `/world/timeline/<doc_id>` | 工作区里内嵌的经典编辑器页面 |

### 17.2 JSON 接口

| 方法 | 路径 | 作用 |
| --- | --- | --- |
| GET | `/api/timeline` | 读整条时间轴（条目 + 视野） |
| POST | `/api/items` | 新建一个条目 |
| PUT / PATCH / DELETE | `/api/items/<item_id>` | 更新（PUT/PATCH）/ 删除一个条目 |
| PUT | `/api/view` | 保存视野（起点 / 终点） |
| — | `/api/<任意未匹配路径>` | 兜底：统一回 JSON 404 |

> 兜底那条用的是 `^api(?:/|$)`，所以连 `/api` 本身也会命中，
> 不会因为「自动补斜杠」的重定向把带请求体的 POST 弄坏。

## 18. 总路由一览

项目总路由（[worldbuilding_timeline/urls.py](../worldbuilding_timeline/urls.py)）
把各块拼在一起：

| 路径 | 归属 |
| --- | --- |
| `/admin/` | Django 自带后台 |
| `/api/world/*` | 工作区 JSON 接口（`world` 应用） |
| `/world` | 工作区页面 |
| `/sw.js` | Service Worker 脚本（必须从根路径发） |
| `/relationship` | 关系树独立页 |
| `/map`、`/map/<view>` | 地图独立页 |
| `/s/<slug>/` | 发布出来的只读站点 |
| `/legacy`、`/api/*` | 经典时间轴（`timeline` 应用） |
| `/login`、`/register`、`/logout` | 表单式账号页 |
| `/maintenance` | 维护页 |
| `/`、`/w` | 302 跳到 `/world` |

> 只读站点、地图独立页、关系树独立页还有自己的一套页面路由，本表只列与接口相关的部分。
