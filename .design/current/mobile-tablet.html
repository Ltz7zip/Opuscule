当前前端只有 640 / 900 两个零散断点，导航、编辑器、地图与时间线仍按桌面尺寸等比缩小。这份稿子把手机与平板拆成两套明确的布局：手机先解决可达性与编辑连续性，平板先解决空间利用率与阅读节奏。

  • 手机基准390 × 844
  • 平板基准1024 × 768 / 834 × 1112
  • 触控目标≥ 44 px
  • 默认主题DARK
  • 设计语言MONO / SERIF
01

三条适配主线

不是把桌面压扁，而是为触屏重新安排层级。

01 / REACH

单手可达

主导航移到底部四格，世界内页面用横向子导航。抽屉、底部面板与工具栏都落在拇指区，页面主操作不再挤在右上角。

bottom bar · sheet · 44px
02 / READ

阅读优先

公开页从多列卡片收成单列叙事，正文 15 / 1.76，保留衬线标题。目录从右栏变成浮球 + 底部面板，不打断长文阅读。

single column · floating toc
03 / WRITE

编辑不缩水

工作区保留完整 Tiptap 能力：键盘上沿吸附格式条，斜杠菜单改为底部面板，块操作走长按菜单；保存状态常驻顶栏，不再依赖底部保存条。

keyboard dock · block sheet
02

断点约定

沿用现有 640 手机断点，新增 1024 平板边界，替换零散的 900 规则。

手机≤ 640px顶部栏 + 底部四格 + 抽屉单列；页面边距 16；正文 15px

03

导航模型

手机是“页面 + 底部去处”，平板是“常驻侧栏 + 主画布”。

手机

≤ 640 · PORTRAIT

全局页：顶栏 + 内容 + 底部四格。
世界页：顶栏 + 横滑子导航；地图 / 时间线用底部面板承载详情。工作区隐藏底栏，改用抽屉 + 编辑工具条。

平板

641 – 1024 · BOTH

工作区把 268 侧栏收成 248，编辑区保持单栏但加大留白；地图与时间线使用“画布 + 320 检查器”，避免在画布上叠弹窗。

桌面

≥ 1025 · UNCHANGED

现有浮层侧栏、右栏目录、hover 工具条全部保留。移动端规则只在 ≤1024 生效，不回写桌面布局。
